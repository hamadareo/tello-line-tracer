# Tello Line Tracer

小型ドローン **DJI Tello** のカメラ映像で床の黒いラインを見つけて、ラインに沿って自動で飛ばすプログラムです。
ブラウザのダッシュボードから、離陸や着陸、パラメータ調整、映像の確認ができます。

## 主な機能

- **ライントレース**: カメラ映像から黒いラインを取り出し、PD 制御とラインの角度を使って機首の向き（ヨー）を調整します
- **カーブ予測と減速**: ズレの変化やラインの角度からカーブを予測して、早めに曲がり始めつつ速度を落とします
- **高度の維持**: Tello の ToF センサー（下向きの距離センサー）で、目標の高さを保ちます
- **コース学習（ラップ機能）**: 1 周分の飛び方を記録して `course_map.json` に保存します。次の周からは記録を先読みして、カーブの手前で減速・旋回します。周回を重ねると、記録が平均されて精度が上がります
- **ラインを見失ったときの復帰**
  1. 約 1 秒: 最後にラインが見えた方向へ旋回して探す
  2. 約 2 秒: 反対方向へ大きく旋回して探す
  3. 約 3 秒: ゆっくり後退しながら旋回する
  4. それでも見つからなければ、自動で着陸する
- **マウスアシスト**: ラインを見失っている間は、カメラ映像の上をマウスでドラッグして手動で誘導できます（左右で旋回、上下で前進・後退）
- **Web ダッシュボード**
  - カメラ映像と、ラインの見つかり方がわかる白黒映像（二値化映像）をリアルタイムで表示
  - バッテリー、高度、速度、ログの表示
  - 制御パラメータを飛ばしながら調整できる

## 必要なもの

- DJI Tello
- Python 3 が使える PC（Wi-Fi で Tello とつなぎます）
- 床に貼る黒いライン（ビニールテープなど）

```bash
pip install -r requirements.txt
```

## 使い方

1. Tello の電源を入れて、PC を Tello の Wi-Fi（`TELLO-xxxxxx`）につなぎます
2. プログラムを起動します

   ```bash
   python3 line_tracer.py
   ```

3. ブラウザで `http://127.0.0.1:5003` を開きます（5003 番が使われているときは、ターミナルに出たアドレスを開いてください）
4. 「離陸」を押すと、ライントレースを始めます
5. コースを学習させたいときは、スタートラインを通るときに「ラップ開始 / 終了」を押します。1 周したらもう一度押すと、記録が保存されます

### 調整できるパラメータ

| 項目 | 初期値 | 説明 |
| --- | --- | --- |
| 目標高度 (`TARGET_HEIGHT`) | 45 cm | 保とうとする高さ |
| ROI 開始位置 | 0 % | 映像の上から何 % の位置より下を処理するか |
| KP ゲイン | 0.4 | ズレに対する旋回の強さ |
| KD ゲイン | 0.5 | ズレが急に大きくなったときの曲がる強さ |
| 前進速度 (`FORWARD_SPEED`) | 30 | まっすぐのときの速度。カーブでは自動で減速します |
| ラインしきい値 (`THRES_VAL`) | 70 | これより暗い部分をラインとみなします |
| 最小 / 最大輪郭面積 | 200 / 5000 | ラインとみなす大きさの範囲。小さなゴミや大きな影を除きます |

初期値は `line_tracer.py` の先頭で変更できます。

## 注意事項

- ドローンは**屋内や安全な場所で**、周りに人や物がない状態で飛ばしてください。いつでも「緊急着陸」を押せるようにしておいてください
- ダッシュボードにはパスワードがありません。また、同じネットワークにいる他の端末からも開ける設定（`0.0.0.0`）になっています。信頼できるネットワークで使ってください
- ドローンを飛ばすときは、その国や地域のルールを守ってください
